College Management System

Technologies Used:

  • Frontend: Angular, SCSS, Bootstrap
  • Backend: Node.js, Express.js
  • Database: MongoDB

Admin Panel

The admin panel includes CRUD for students, placements, events, rank holders, and visionaries. Secure access and intuitive modals for form submissions.

Client Side

Students and visitors can explore courses, events, contact the college, and view latest updates through a modern UI with parallax and animations.

More Features

  • Fully responsive UI
  • Integrated contact form with enquiry tracking
  • Dynamic course filtering system
  • Admin dashboard with modals and real-time updates
